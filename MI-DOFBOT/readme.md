# MI-DOFBOT

DOFBOT 机械臂控制目录。支持键盘控制和脑环控制。公共训练由 `TrainUser/train_user.py` 完成，最终模型由本目录的 `brain_control.py` 复用。

## 文件说明

| 文件 / 目录 | 用途 |
|---|---|
| `keyboard_control.py` | 机械臂键盘控制入口。 |
| `brain_control.py` | 机械臂脑环控制入口。 |
| `arm_hardware.py` | DOFBOT 机械臂硬件适配（真实 `ArmController` 与 `SimulatedArmController`），以及校准文件的读取。 |
| `arm_device.py` | 统一脑控用的机械臂适配器：意图映射为舵机动作，附加动作为开合夹爪，急停为复位，到达限位时拒绝动作。 |
| `arm_calibration.json` | 可选的校准文件：夹爪角度、限位、预备姿态、动作方向。不存在时使用未校准的默认值。 |
| `Arm_Lib (Windows)/` | DOFBOT 底层串口控制库。 |
| `readme.md` | 本说明文件。 |

## 脑环接口

脑环串口统一在根目录 `bci_interface.py` 中配置。通常不需要在本目录里修改代码。

## 键盘控制

建议先 dry-run 或保持机械臂处于安全位置（需要 `pip install pynput`）：

```bash
python MI-DOFBOT/keyboard_control.py --dry-run
python MI-DOFBOT/keyboard_control.py --arm-port COM4
```

| 按键 | 动作 |
|---|---|
| A / D | 1 号舵机（底座）左 / 右 |
| W / S | 2 号舵机 前 / 后 |
| ↑ / ↓ | 3 号舵机 上 / 下 |
| Q / E | 4 号舵机（腕部）减 / 增 |
| 空格 / X | 6 号舵机（夹爪）角度 增 / 减 |
| G | 按校准角度开合夹爪 |
| P | 回到预备姿态（校准文件里有 `ready` 时） |
| R / Esc | 复位 / 退出 |

长按连续动作。每次动作后终端会打印六个舵机的当前角度，校准时直接抄进 `arm_calibration.json`。

## 脑环控制

首次建议使用 dry-run：

```bash
python MI-DOFBOT/brain_control.py --dry-run
```

确认信号和逻辑正常后，再连接真实机械臂：

```bash
python MI-DOFBOT/brain_control.py --arm-port COM4
```

默认模型路径：

```text
src/models/FinalModel.pth
```

三种脱离真实机械臂的方式：

| 方式 | 命令 | 说明 |
|---|---|---|
| dry-run | `--dry-run` | 走真实适配器但不下发串口指令，最贴近真机。 |
| 仿真臂 | `--simulated` | 用内存中的 `SimulatedArmController` 记录动作，完全不加载任何硬件库。 |
| 仅测脑环 | `--test-brain` | 只读脑环、报告窗口质量，不连接机械臂。 |

## 校准文件（arm_calibration.json）

夹爪角度、限位、预备姿态这些数值必须在真机上量出来。把它们写进 `MI-DOFBOT/arm_calibration.json`，键盘控制、脑环控制和控制面板（模拟和真机）都会自动读取；文件不存在时使用未校准的默认值。也可以用 `--calibration <路径>` 指定其他文件。

```json
{
  "gripper": {"open": 60, "close": 135},
  "limits": {"2": [30, 150], "3": [10, 100]},
  "poses": {"ready": [90, 80, 50, 50, 135]},
  "steps": {"arm_forward": [2, -1], "arm_backward": [2, 1]}
}
```

上面的数字只是格式示例，**不要直接用在真机上**。四个字段都可以省略：

| 字段 | 含义 |
|---|---|
| `gripper` | 夹爪张开 / 闭合时 6 号舵机的角度。也可以用 `--gripper-open-angle` / `--gripper-close-angle` 临时覆盖。 |
| `limits` | 每个舵机允许的角度范围（软限位）。点动不会超出范围；脑控和面板到达限位时提示“已到限位”，不再下发指令。 |
| `poses` | 命名姿态。5 个角度表示 1–5 号舵机（不动夹爪），6 个角度连夹爪一起设置。名为 `ready` 的姿态是**预备姿态**：连接后机械臂先到这里，脑控从这里开始。姿态必须在限位之内。 |
| `steps` | 修改某个动作对应的舵机和方向（`[舵机编号, 1 或 -1]`），真机上方向相反时用它翻转。 |

文件写错（角度越界、姿态超出限位、未知动作）时程序会在机械臂运动之前报错退出。复位姿态固定为 `[90, 90, 90, 90, 135, 90]`，急停、脑环断开和退出时仍然回到复位姿态。

## 脑控逻辑（EEG → 控制命令）

控制逻辑来自三个设备共用的 `bin/control.py`（详见根目录 README 的“统一控制方式”），本目录只保留机械臂的接线（`arm_device.py`）。决策管线：

1. **眨眼是离散事件**：双眨眼在三个模式间循环（升降 → 前后 → 转弯）；单眨眼开合夹爪，但在转弯模式（默认规则）下改为切换旋转方向。
2. **模式内产生"原始意图"**：
   - 升降 / 前后：比较窗口内 attention/meditation 计数，带**死区**（两者都低于阈值 → 静止 `rest`）。
   - 转弯（默认 `--turning-source rule`）：`bin.decoding.FocusSteer`，窗口内 attention ≥ `--focus-threshold` 的采样数达到 `--min-decision-count` 时向当前方向旋转，否则 `rest`。
   - 转弯（`--turning-source model`）：调用共享模型的 `predict_proba`，用 **置信度门控** 得到 `left / right / rest`（softmax 最大值低于阈值 → 归入 `rest`，不乱动）。
3. **多窗投票（滞回）**：原始意图先进入 `VoteWindow`，同一意图在最近若干窗口里达到票数才真正执行——单个噪声窗口无法带动舵机。机械臂默认 3 窗 2 票，另外两个设备默认关闭。
4. **安全**：脑环断开（poorSignal=200）时机械臂复位并回到升降模式；程序退出时复位；到达限位的动作被拒绝。

也可以用 [统一控制面板](../control_panel/README.md) 在网页上选择本设备，统一显示脑电、模式和急停。面板的“设备状态”卡片显示六个舵机的下发角度、限位和姿态示意图；手动控制区多出一排只给操作员用的按钮（复位、预备姿态、腕部 ±、夹爪旋转 ±、夹爪角度 ±），脑控不会触发它们。

## 演示流程（抓取 + 升降 + 前后 + 旋转）

准备（操作员用面板的手动按钮完成，或提前写进校准文件）：

1. 物块放在预备姿态下夹爪的正前下方，夹爪张开。
2. 被试戴好脑环，面板上“信号”显示良好后启动脑控。

脑控（被试完成）：

| 步骤 | 模式 | 操作 | 机械臂动作 |
|---|---|---|---|
| 1 | 升降 | 放松 | 下降到物块高度 |
| 2 | 升降 | 单眨眼 | 夹爪闭合，夹住物块 |
| 3 | 升降 | 专注 | 抬起物块 |
| 4 | 前后 | 双眨眼切换模式，再专注 / 放松 | 前伸 / 后收 |
| 5 | 转弯 | 双眨眼切换模式，专注（单眨眼换方向） | 底座旋转到放置位置 |
| 6 | 升降 | 双眨眼切换模式，放松后单眨眼 | 下降并松开物块 |

没有真机时，同一流程可以在控制面板里用模拟机械臂和模拟脑环完整排练。

## 真机检查清单（首次上真机前逐项确认）

代码里下面这些数值都没有在真机上验证过，请按顺序检查，把结果写进校准文件：

1. **串口**：`--arm-port`（Windows 下如 `COM4`）。先用 `keyboard_control.py` 确认能连接、R 能复位。
2. **夹爪方向**：默认张开 120° / 闭合 60°。Yahboom 官方例程是 60° 松开、135° 夹紧，方向很可能相反。用空格 / X 点动夹爪，记下真正张开和夹紧物块的角度，写进 `gripper`。
3. **动作方向**：W / S、↑ / ↓、A / D 的实际方向是否与“前后、升降、左右”一致；不一致就在 `steps` 里翻转。
4. **预备姿态**：把机械臂点动到夹爪水平、位于物块上方的位置，记下角度写进 `poses.ready`。从复位姿态（竖直向上）一步步点动到桌面太慢，演示应从预备姿态开始。
5. **限位**：分别点动到快要碰到桌面、底座和自身的位置，把留有余量的角度写进 `limits`。
6. **步长**：脑控每 3 秒最多动一步，默认每步 5°。动作太慢可以加 `--angle-step 10`（最大 10）。
7. **急停**：面板右上角急停或 Esc 会复位机械臂（夹爪回到 90°，夹着的物块会松开），先空载试一次。

## 常用参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `--turning-source` | rule | 转弯模式信号来源：`rule` 专注执行、单眨眼换方向；`model` 共享模型。 |
| `--focus-threshold` | 55 | 转弯模式中算作“专注”的 attention 值；用 `--test-brain` 打印的分布为自己校准。 |
| `--confidence-threshold` | 0.5 | `model` 转弯模式下 softmax 的静息带阈值。 |
| `--vote-window` / `--vote-min` | 3 / 2 | 多窗投票的窗口长度与所需票数；设为 `1 / 1` 关闭平滑。 |
| `--min-decision-count` | 15 | attention/meditation 死区：两者都低于它则静止。 |
| `--decision-margin` | 3 | attention 与 meditation 计数至少相差此值才选边。 |
| `--angle-step` | 5 | 每次动作的舵机步进角度（1–10）。 |
| `--calibration` | `MI-DOFBOT/arm_calibration.json` | 校准文件路径。 |
| `--gripper-open-angle` / `--gripper-close-angle` | 校准文件的值 | 临时覆盖夹爪张开 / 闭合角度。 |
| `--blink-threshold` | 100 | 眨眼强度超过它才算一次眨眼。`--test-brain` 会打印每个窗口的眨眼强度峰值，用来区分自然眨眼和用力眨眼。 |

## 安全建议

- 首次运行一定先使用 `--dry-run`。
- 保持机械臂周围无遮挡。
- 如果动作方向不符合预期，先用 `keyboard_control.py` 校验舵机方向，再在校准文件的 `steps` 里翻转。
- 自然眨眼也可能被识别成单眨眼，导致夹爪误开合。上真机前用 `--test-brain` 看眨眼强度峰值，把 `--blink-threshold` 调到自然眨眼之上。
