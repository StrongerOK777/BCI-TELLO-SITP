## 📋 项目简介

本项目提供一个基于 **Python** 与 **pynput** 库的实时键盘控制程序，专为基于 `Arm_Lib` 驱动的 **12 自由度串行总线舵机机械臂**（如亚博智能 DOFBOT-SE 系列）设计。

与传统的“输入指令 + 回车”控制方式不同，本程序实现了**真正的实时监听**：

- 按下按键，机械臂**立刻响应**；
- 松开按键，运动**立即停止**；
- 支持**多键同时按下**，实现复合运动。

无论是初学者调试舵机角度，还是资深玩家进行动作编排，都能获得流畅的控制体验。

---

## ✨ 主要特性

- **⚡ 实时响应**：基于 `pynput` 全局键盘钩子，延迟低于 50ms。
- **🔄 长按连续控制**：持续按住 `W`、`A`、`S`、`D` 等按键，舵机会以固定步长连续运动。
- **🛡️ 硬件保护**：内置舵机角度范围限制（S1-S4, S6: 0-180°；S5: 0-270°），避免超限损坏舵机。
- **📟 终端状态显示**：连接成功时显示固件版本，支持随时查看当前所有舵机角度。
- **🎯 一键归中**：按下 `R` 键即可将所有舵机恢复至安全的中位姿态。
- **🧵 线程安全设计**：控制逻辑与键盘监听分离，运行稳定不卡顿。

## 📦 安装与配置

### 1️⃣ 克隆或下载项目

```bash
git clone https://github.com/907nicerice/NiceRice-with-DOFBOT-SE-NEUROSKY.git
cd dofbot-keyboard-control
```

### 2️⃣ 安装 Python 依赖

```bash
pip install pynput pyserial
```

### 3️⃣ 准备 Arm_Lib 库

将官方提供的 Arm_Lib 库文件放置在项目根目录下。常见的文件名可能是：

- Arm_Lib.py (Python 源码)
- Arm_Lib.cp37-win_amd64.pyd (Windows 编译版本)
- Arm_Lib.so (Linux 编译版本)

注意：如果 Arm_Lib 已通过 `pip install Arm_Lib-xxx.whl` 安装至系统环境，此步可跳过。

### 4️⃣ 连接硬件并确定端口号

- Windows：打开"设备管理器" → "端口 (COM 和 LPT)"，查找类似 `USB-SERIAL CH340 (COM4)` 的条目。
- Linux：终端执行 `ls /dev/ttyUSB*` 或 `ls /dev/ttyACM*`，通常为 `/dev/ttyUSB0`。

## 🚀 快速开始

打开终端（命令行），进入项目目录。

运行程序：

```bash
python arm_control.py
```

输入 COM 端口（Windows 示例）：

```
输入COM端口 (默认com3): com4
```

看到成功提示：

```
[✓] 机械臂连接成功
[✓] 固件版本: v1.0
```

开始控制！按下键盘上的 W、A、S、D 等按键，机械臂将实时响应。

## 🎮 控制映射详解

| 按键组合 | 对应舵机 | 动作描述 | 角度范围 |
|----------|----------|----------|----------|
| W (按住) | 舵机 2 | 机械臂前伸（角度增加） | 0° → 180° |
| S (按住) | 舵机 2 | 机械臂后缩（角度减少） | 180° → 0° |
| A (按住) | 舵机 1 | 底座左转（角度减少） | 180° → 0° |
| D (按住) | 舵机 1 | 底座右转（角度增加） | 0° → 180° |
| ↑ (上箭头，按住) | 舵机 3 | 大臂抬升（角度增加） | 0° → 180° |
| ↓ (下箭头，按住) | 舵机 3 | 大臂下降（角度减少） | 180° → 0° |
| Q (按住) | 舵机 4 | 小臂下压（角度减少） | 180° → 0° |
| E (按住) | 舵机 4 | 小臂上抬（角度增加） | 0° → 180° |
| Space (空格，按住) | 舵机 6 | 末端夹持器张开（角度增加） | 0° → 180° |
| X (按住) | 舵机 6 | 末端夹持器闭合（角度减少） | 180° → 0° |
| R (点按) | 所有舵机 | 一键复位至中位安全姿态 | - |
| H (点按) | - | 在终端显示控制菜单 | - |
| ESC 或 Ctrl+C | - | 安全退出程序 | - |

💡 小技巧：可以同时按住 W 和 A，机械臂将边前伸边左转，实现复合轨迹运动。

## 🏗️ 代码结构说明

```
arm_control.py
├── ArmController 类
│   ├── __init__()          # 连接机械臂，初始化变量，获取固件版本
│   ├── get_version()       # 读取底层控制器版本信息
│   ├── display_menu()      # 打印控制说明菜单
│   ├── write_servo_angle() # 底层写角度接口（带限幅保护）
│   ├── read_servo_angle()  # 底层读角度接口
│   ├── control_servo()     # 核心控制逻辑：基于当前缓存角度和步长计算新角度
│   ├── show_all_angles()   # 查询并打印所有舵机实时角度
│   ├── reset_all()         # 一键复位所有舵机到中位
│   ├── on_press()          # pynput 按键按下回调
│   ├── on_release()        # pynput 按键释放回调
│   ├── update_controls()   # 主循环中调用的状态更新函数（处理长按连续运动）
│   └── run()               # 启动键盘监听线程，进入主事件循环
└── main()                  # 入口函数：获取端口号，创建控制器实例，启动运行
```

工作流程：

- `pynput.Listener` 在后台线程捕获键盘事件。
- 按键状态存入 `self.keys_pressed` 集合。
- 主线程每隔 0.01 秒调用 `update_controls()`，检查集合中是否有按键被按住。
- 若按住时间超过 `update_interval`（默认 0.05 秒），则调用 `control_servo()` 修改角度。
- 角度写入串口，机械臂运动。

⚙️ 自定义配置指南
你无需修改底层库，只需调整类初始化参数即可改变控制手感。

### 修改控制步长（每次按键调整的角度）

编辑 `__init__` 方法中的 `self.angle_step` 变量：

```python
self.angle_step = 3   # 原为 5，改为 3 则微调更细腻
```

### 修改运动速度

在 `write_servo_angle` 方法中，修改 `move_time` 参数（单位：毫秒）：

```python
def write_servo_angle(self, servo_id, angle, move_time=500):  # 改为 500ms 运动更平缓
```

### 修改长按响应间隔

调整 `self.update_interval`（单位：秒），值越小响应越快，但 CPU 占用略高：

```python
self.update_interval = 0.03   # 原 0.05，改为 30ms 响应更灵敏
```

### 修改默认 COM 端口

在文件末尾 `main()` 函数中：

```python
com_port = input("输入COM端口 (默认com3): ").strip()
if not com_port:
    com_port = "com4"  # 将默认值改为你的常用端口
```

# 🐞 常见问题排查

### ❌ 问题 1：运行后提示 [✗] 机械臂连接失败

可能原因与解决步骤：

端口号错误

确认设备管理器中显示的 COM 口（如 COM5），输入时注意大小写不敏感，但必须准确。

串口被占用

关闭所有可能占用该串口的软件（如 Arduino IDE、官方上位机、串口调试助手）。

#### Linux 权限不足

执行 `sudo chmod 666 /dev/ttyUSB0` 临时赋权，或永久加入 dialout 组：

```bash
sudo usermod -a -G dialout $USER
# 注销后重新登录生效
```

#### 驱动问题

确保 CH340 或 CP210x 驱动已正确安装。

### ❌ 问题 2：按键有反应（终端无报错）但机械臂不动

检查机械臂的 **外部电源** 是否已接通（部分型号 USB 仅供电给控制板，舵机需独立 12V 电源）。

在代码中添加调试打印，查看 `write_servo_angle` 是否被调用：

```python
print(f"Writing servo {servo_id} to {angle}")
```

### ❌ 问题 3：机械臂运动一顿一顿或响应迟钝

尝试减小 `self.update_interval` 至 0.02。

尝试增加 `move_time` 至 300，避免指令堆积。

关闭其他占用 USB 带宽的设备（如高清摄像头）。

### ❌ 问题 4：按下按键后，终端显示了菜单，但机械臂依然在动

这是正常现象。H 键只是打印菜单，不会影响正在进行的运动。如需停止运动，松开所有按键即可。

### ❌ 问题 5：如何让机械臂保持某个姿势不动？

松开所有按键，机械臂会停留在最后一次设定的角度。程序不会主动发送停止指令（舵机自带保持力矩）。

🧪 高级玩法与扩展

1. 录制与回放动作序列
你可以基于本程序轻松扩展动作录制功能。核心思路是将 write_servo_angle 调用时的 (时间戳, 舵机ID, 角度) 记录到列表，然后通过 time.sleep 回放。

2. 接入游戏手柄
修改 pynput 部分为 pygame 或 inputs 库，即可用手柄摇杆控制机械臂，实现更直观的操控。

3. 增加逆运动学（IK）控制
在 ArmController 中添加坐标解算函数，输入 (x, y, z) 坐标，自动解算 1~4 号舵机角度，实现末端位置控制。

4. 与视觉识别联动
结合 OpenCV 识别色块或人脸，调用 Arm_serial_servo_write6 实现追踪抓取。
